Getting Started
시작하기
첫 화면
앱에 들어오면 자동으로 유럽 채용공고를 수집해요. 처음 로딩에 10~20초 정도 걸릴 수 있어요.
로딩 완료 후 상단에 "✅ N개 유럽 채용공고 로드 완료" 메시지가 뜨면 준비 완료예요.
📱 모바일 사용
채용공고, 저장목록, 지원 트래커는 모바일에서도 사용할 수 있어요.
AI 분석, 스킬맵 등 나머지 메뉴는 PC 환경을 권장해요.
💼
Job Search
채용공고 탐색
🔎 검색 사용법
상단 검색창에 직무명, 도시명, 스킬 등을 입력해서 검색할 수 있어요.
OR 조건 검색도 가능해요: Data Analyst OR Marketing Manager
검색창과 필터는 동시에 조합해서 사용할 수 있어요.
필터를 선택한 후에도 검색창에 지역명, 회사명 등 추가 검색어 입력이 가능해요.
🎛️ 필터 종류
필터설명
🌍 국가영국·독일·네덜란드·스페인·프랑스 등 국가별 필터
💼 직종데이터, 마케팅, 개발, HR, 운영/물류·SCM, 경영/전략, 금융
직종 위에 마우스를 올리면 포함 포지션 예시가 나와요
🛂 비자비자 스폰서 확정 공고만 필터링
🏠 근무형태원격(Remote), 하이브리드, 오피스
🌐 언어English, German, French 등
채용공고 작성 언어 기반 + 영어 능숙자 명시된 경우 영어로 표시
📊 경력Entry/Intern · Junior · Mid-level · Senior · Lead · Director

Job Detail
공고 상세 · 회사 후기 연동
💬 Reddit 면접 후기
해당 회사명으로 Reddit 커뮤니티에서 면접·입사·회사 후기를 자동 검색해요.
Glassdoor는 로그인 없이 접근이 제한되어 Reddit과 Kununu로 대체했어요.
⚠️ 항상 결과가 있는 건 아니에요. 소규모 회사나 인지도가 낮은 곳은 후기가 없을 수 있고, 회사명이 일반 단어와 겹칠 때 관련 없는 글이 뜰 수 있어요.
결과가 부족하면 "Reddit에서 더 보기 →" 링크로 직접 검색하세요.
🏢 Kununu 회사 평가
독일어권(독일·오스트리아·스위스)에서 많이 쓰는 Glassdoor 같은 서비스예요.
API가 없어서 회사명으로 Kununu 검색 페이지를 자동으로 연결해줘요.
⚠️ 간혹 URL명이 달라 결과가 안 나올 수 있어요. 그 경우 Kununu 검색창에서 직접 회사명을 검색하세요. 독일어권 회사가 아니면 결과가 없을 수 있어요.

AI Tools
AI 기능
🔍 JD 인사이트 (채용공고 분석)
채용공고 내용을 붙여넣으면 핵심 정보를 자동으로 추출해줘요.
1
관심 있는 채용공고 내용 전체 복사 후 텍스트 박스에 붙여넣기
2
채용공고 URL(LinkedIn 제외)을 붙이면 텍스트를 자동으로 가져와요
3
분석 방법 선택
🔍 즉시 분석
NLP 기반 자동 분석 (AI 아님)
급여·근무형태·언어·스킬·외국인 가능성 점수를 바로 보여줘요.
빠르지만 일부 오차가 생길 수 있어요.
🤖 ChatGPT로 상세 분석
ChatGPT 프롬프트가 자동 생성돼요.
더 정확하고 상세한 분석이 필요할 때 사용하세요.
📊 매칭 적합도
이력서를 직접 텍스트로 붙여넣거나 PDF, Word 파일을 업로드하면 이력서 텍스트를 자동으로 읽어내요.
채용공고 카드 하단의 「AI 매칭에 사용」을 클릭하거나 직접 공고 내용을 붙여넣은 후 ChatGPT를 통해 적합도를 분석해요.
작동이 안 될 시 생성된 프롬프트를 복사해서 직접 붙여넣으세요.
🎯 AI 추천 공고
매칭 적합도 메뉴에서 이력서를 저장해두면 사용 가능해요.
현재 수집된 공고 중 내 이력서와 가장 잘 맞는 공고를 AI가 추천해줘요.
💡 매칭률은 합격률이 아니라 면접 가능성으로 참고해주세요.
✍️ 커버레터 작성
이력서 + 채용공고 입력 → ChatGPT가 커버레터 초안을 생성해줘요.
채용공고 상세에서 「커버레터에 사용」 버튼을 누르면 공고가 자동으로 채워져요.

정보 메뉴
📈 직종 트렌드
각 나라별로 채용공고 수가 많은 직군을 그래프로 보여줘요.
가고 싶은 나라는 있지만 아직 어느 분야로 이직할지 고민 중인 분들께 유용해요.
🗺️ 직종별 스킬맵
직종별로 유럽 채용 시장에서 요구되는 스킬을 시각화해줘요.
업계 기준 데이터 + 실제 수집된 공고 데이터를 혼합해서 보여줘요.
수집 공고가 많을수록 실제 데이터 비중이 높아져요.
본인 직군을 선택하면 스킬 레이더 차트로 현재 시장 트렌드를 확인할 수 있어요.

Notice
알아두면 좋은 것들
공고 정확도
무료 API 기반이라 공고 품질이 LinkedIn 등과 다를 수 있어요. 비자 스폰서 여부는 키워드 기반으로 감지하기 때문에 실제와 다를 수 있어요. 지원 전 반드시 원문을 확인해주세요.
공고 업데이트
하루 1~2회 자동 수집돼요.
일부 유럽 국가 미포함
북유럽 등 일부 국가는 수집 플랫폼 특성상 포함되지 않을 수 있어요. 현재 추가 소스를 찾고 있지만 불확실한 상황이에요.
개인 프로젝트
현재 비개발자의 1인 개발·운영 중인 프로젝트예요. 불편한 점이나 버그는 피드백 폼에 남겨주시면 빠르게 반영할게요 😊
